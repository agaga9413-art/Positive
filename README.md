# Minseok Office · 피클 본부

개인 AI 비서(Pickle)의 작업 공간을 한 장의 화면으로 보여주는 **단일 파일 웹 앱** 데모입니다.
빌드 도구도, 서버도, 외부 이미지 요청도 없습니다. `index.html` 하나만 열면 그대로 동작합니다.

> 모든 내용은 **샘플 데이터**입니다. 실제 개인 일정·예약·건강 정보는 들어 있지 않습니다.

## 미리보기

https://agaga9413-art.github.io/Positive/

## 구성

- **오피스** — 아이소메트릭 3D 오피스 일러스트 위의 6개 핫스팟(대회의실 · 지휘실 · 여행·예약 · 일정·건강 · 혜택·포인트 · 라운지). 핀을 탭하면 해당 공간의 현황이 바텀시트로 열립니다.
- **회의실** — 결정이 필요한 안건과 선택지 비교
- **작업실** — 가동 중인 루틴과 최근 완료 기록
- **현황** — 다가오는 일정 타임라인, D-day 자동 계산
- **메모** — 기기에 저장되는 빠른 메모(`localStorage`)

## 특징

- 100% 자기완결형: 일러스트가 base64 PNG로 HTML 안에 들어 있어 오프라인에서도 그대로 보입니다.
- 모바일 우선(iOS 스타일) 레이아웃, 세이프 에어리어 대응.
- `모션 ON/OFF` 토글로 부드러운 부유·펄스 애니메이션을 끌 수 있습니다.
- 바텀시트는 배경 탭, 닫기 버튼, 아래로 스와이프, `Esc`로 닫힙니다.
- 다크 모드·외부 폰트·트래커·쿠키 없음.

## 열기

```bash
open index.html          # macOS
# 또는 파일을 브라우저로 드래그
```

iPhone에서는 파일을 열거나, Safari에서 페이지를 연 뒤 **홈 화면에 추가**하면 앱처럼 실행됩니다.
